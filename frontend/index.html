MFA VAULT

Zero-trust auth demo

Password + authenticator app, the way real systems do it

A minimal, from-scratch implementation of two-factor login: bcrypt password hashing, RFC 6238 time-based one-time codes (the same standard behind Google Authenticator), single-use backup codes, and short-lived JWT sessions. No auth-as-a-service, no third-party SDK — every step is code you can walk through.

Factor 1password (bcrypt hash)
Factor 2TOTP (RFC 6238)
Recovery8 single-use backup codes
SessionJWT, 30 min expiry
Brute forcelockout after 5 failed attempts
